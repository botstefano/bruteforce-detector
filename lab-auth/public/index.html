Configura tu segundo factor

Añade esta clave en Google Authenticator, Microsoft Authenticator, Aegis u otra aplicación TOTP. Selecciona la opción para introducir una clave de configuración manual.

La clave es personal. No la compartas. La aplicación generará un código nuevo de seis dígitos cada 30 segundos.

La contraseña y el código TOTP se validan localmente y nunca se transmiten a Centinela. El detector recibe solo el identificador, el resultado y la IP verificada.
